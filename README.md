# Andén Cero · Sitio web

Página de presentación de **Andén Cero**, un juego de eliminación multijugador donde plantás bombas en una estación de tren abandonada para eliminar a tus rivales.

**Ver la página:** https://matiasfauda23.github.io/anden-cero-web/

## ¿Qué es este repositorio?

Este repositorio contiene solo el sitio web del juego. Es una página estática (HTML y CSS, sin frameworks) publicada con GitHub Pages. El código del juego está en un repositorio aparte.

La página incluye:

- Presentación del juego y su propuesta.
- Tráiler.
- Los cuatro modos de juego: Battle Royale, PvP 2 vs 2, Supervivencia y Minijuego.
- El equipo creador.
- Enlace de descarga de la build para Windows.

## Sobre el juego

- **Género:** eliminación multijugador con bombas.
- **Jugadores:** de 1 a 4, online con un código de sala.
- **Plataforma:** PC con Windows.
- **Motor:** Unity 6, con Netcode for GameObjects y Unity Relay.

## Descargar el juego

Descargá la última versión desde la sección [Releases](../../releases/latest), descomprimí el `.zip` y ejecutá el archivo `.exe`.

> Windows puede mostrar un aviso de SmartScreen porque el ejecutable no está firmado. Elegí **Más información → Ejecutar de todas formas**.
